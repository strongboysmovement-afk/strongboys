# Хүчирхэг хөвгүүд — вэб сайт

Энэ бол GitHub Pages дээр ажиллах статик вэб сайт.

## Агуулга
- `index.html` — нүүр хуудас, хөтөлбөрийн танилцуулга, чиглэлүүд, мэдээний жишээ хэсэг, холбоо барих.
- Гар утас болон компьютерын дэлгэцэд тохирсон responsive загвар.

## GitHub Pages асаах
Repository → Settings → Pages → Build and deployment → Deploy from a branch → Branch: main → Folder: / (root) → Save.

## Мэдээ шинэчлэх
Одоогийн хувилбарт мэдээний хэсэг нь загвар жишээтэй; олон хэрэглэгч нэвтэрч мэдээ оруулах админ систем хараахан холбогдоогүй. Мэдээг нийтлэхийн тулд `index.html` доторх `id="newsGrid"` хэсгийн картуудыг шинэчилнэ. Дараагийн шатанд тусдаа CMS/нэвтрэх систем холбож болно.
