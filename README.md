# Хүчирхэг хөвгүүд — албан ёсны вэб сайт

Нүүр хуудас болон гишүүдийн цахим булантай, GitHub Pages + Supabase дээр ажиллах статик вэб сайт.

## Хуудас
- `index.html` — хөтөлбөрийн танилцуулга, чиглэлүүд, Supabase-ээс автоматаар татах мэдээний хэсэг.
- `members.html` — гишүүний бүртгэл/нэвтрэлт, гишүүний код, баталгаажуулалт, зарлал, санал асуулга, Google Forms, арга хэмжээний бүртгэл, админ удирдлага.

## Нийтлэх
GitHub repository → Settings → Pages → Build and deployment:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

Нийтлэх хаяг: https://strongboysmovement-afk.github.io/strongboys/

## Supabase
Вэб клиентэд зөвхөн publishable key ашиглана. `service_role` эсвэл secret key-г HTML/JavaScript-д хэзээ ч оруулахгүй.
Мэдээллийн сангийн хүснэгтүүд RLS хамгаалалттай. Бүртгүүлсэн хэрэглэгч анхдагчаар pending төлөвтэй бөгөөд баталгаажсан гишүүн биш бол гишүүдийн агуулгад нэвтрэхгүй.

### Эхний админ тохируулах
1. Сайт дээр эзэмшигчийн имэйлээр эхний бүртгэл үүсгэнэ.
2. Имэйл баталгаажуулж нэвтэрнэ.
3. Supabase Dashboard → SQL Editor дээр зөвхөн тухайн анхны эзэмшигчийн бүртгэлийг admin болгож баталгаажуулна. Энэ үйлдлийг веб клиентээс хийх боломжгүй; эрхийн аюулгүй байдлыг хамгаална.
4. Үүний дараа админ самбараас бусад гишүүдийн хүсэлтийг баталгаажуулна.

Жишээ SQL-г ашиглахдаа зөвхөн өөрийн баталгаажуулсан бүртгэлийн имэйлийг тавина:
```sql
update public.profiles p
set role = 'admin', membership_status = 'approved'
from auth.users u
where p.id = u.id
  and lower(u.email) = lower('OWNER_EMAIL_HERE');
```

## Админ боломжууд
- Нүүр хуудсанд мэдээ нийтлэх (мэдээний feed автоматаар шинэчлэгдэнэ)
- Гишүүдэд зарлал хүргэх
- Санал асуулга үүсгэх, нэг гишүүн нэг удаа санал өгөх
- Google Forms холбоос нийтлэх
- Арга хэмжээ нийтлэх, гишүүдийн бүртгэл хүлээн авах
- Гишүүний хүсэлтийг батлах, татгалзах, түр зогсоох

- Логоны эх файл хараахан репод ороогүй тул түр тэмдэглэгээ ашиглаж байна.
